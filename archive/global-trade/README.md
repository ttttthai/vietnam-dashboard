# Global Trade (archived standalone project)

https://claude.ai/artifact/W2DPd9EjazZ2P8dZou1bkt). On 2026-11-02 it was merged into this dashboard as chapter 2 of
the Geopolitics tab ("Dòng chảy thương mại / Trade currents"):

- data → `data/geopolitics.json` → `TRADE_CUR` (Geopolitics agent; embed with `python3 tools/build/embed_data.py geopolitics`)
- code → `tcChapter` / `tcInit` in `vietnam_dashboard.html`, next to `renderGeoStory`

Edit the dashboard, not this file; it is kept for reference only.
